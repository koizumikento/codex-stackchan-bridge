# stackchan_msgs

ROS 2 message, service, and action definitions shared by the CLI, bridge nodes, and firmware.

This package should stay small and stable. It is the contract between Codex-facing commands and robot-facing behavior.

Interface details live in [../../docs/ros-interface.md](../../docs/ros-interface.md).

Use [../../docs/ros2-container.md](../../docs/ros2-container.md) for a
containerized ROS 2 Jazzy environment that can build these interfaces without
installing ROS 2 on the host.
